# /components — les briques d'interface réutilisables

Composants sans logique métier : on leur passe des données en props, ils
affichent et remontent les interactions via des callbacks.

- `CarteInteractive` — la carte SVG cliquable (react-native-svg).
- `FlashCard` — une carte question/réponse qui se retourne.

Le style suit les Apple Human Interface Guidelines et doit rester lisible à
7h du matin : voir `.claude/skills/conventions-ui/`.
